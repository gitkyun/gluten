# IA.md

# Gluten Information Architecture

## IA Goal

This document defines:
- navigation hierarchy
- screen architecture
- information hierarchy
- exploration structure
- discovery relationships
- interaction entry points

The purpose is not UI description.

The purpose is:
- structural clarity
- exploration flow definition
- information prioritization
- navigation role separation

---

# IA Philosophy

## Core Principle

Gluten is structured around exploration behavior, not functional categorization.

Traditional apps organize by:
- utility
- search
- information type

Gluten organizes by:
- exploration state
- discovery behavior
- taste accumulation
- visit context

---

# Exploration Structure

```text
Discovery
→ Exploration
→ Save
→ Visit Context
→ Review
→ Taste Accumulation
→ Re-exploration
```

All IA layers support this loop.

## Mood 시스템 (5개)

기존 IA의 추상적 mood axis는 5개 색상 토큰으로 구체화됨.

| Mood Key | Label (Near 필터) | Color Token | 의미 |
|----------|-------------------|-------------|------|
| sweet | 달콤 | `--gluten-mood-sweet` (#FF602E) | 따뜻한 / 햇살 / 브런치 |
| savory | 묵직 | `--gluten-mood-savory` (#7A2E2E) | 빈티지 / 우드톤 / 혼자 |
| healthy | 건강 | `--gluten-mood-healthy` (#6B8F2E) | 미니멀 / 조용한 / 작업 |
| specialty | 특별 | `--gluten-mood-specialty` (#D9A11A) | 모던 / 루프톱 / 데이트 |
| pixel | (없음) | `--gluten-mood-pixel` (#6B5BD9) | 시즈널 / 한정 / 실험 |

Mood는 색상 토큰일 뿐 아니라 베이커리·게시물·필터 칩 전반에 일관 적용되는 IA 축.

## Bottom Navigation (확정)

| Tab | Korean | Icon | 핵심 행동 |
|-----|--------|------|----------|
| explore | 발견 | sparkles | Discovery |
| near | 내 주변 | map-pin | 실세계 탐색 |
| search | 검색 | search | 다차원 검색 및 탐색 |
| social | 소셜 | users | 사람 기반 탐색 |
| profile | 마이 | user | 취향 아카이브 |

* **레이아웃**: 5개 탭 아이콘이 동일 평면에 배치되며, 선택된 탭만 활성화 색상(filled 컴퍼스/돋보기 등)으로 하이라이팅됨.
* **뷰 상태 보존**: 탭 전환 시 화면을 다시 그리지 않고 DOM 상에 항상 유지(`display: none/block` 토글)하여 스크롤 위치와 컴포넌트 상태를 완전히 보존.
* **오버레이 중첩 시 숨김**: 오버레이 스택(`overlayStack`)에 하나라도 활성화된 화면이 있으면 Bottom Nav가 화면에서 숨겨짐.

## Near IA (구체)

### Map + Sheet 구조
* **동적 필터 연동**: 상단 카테고리 칩 필터('소금빵', '지금 한가', '크루아상' 등) 클릭 시 지도 상의 마커 핀과 바텀 시트 리스트(`SheetList`)가 실시간 필터링 반영.
* **상태 동기화**: 칩 필터 변경 시 지도 위의 말풍선 팝업이 초기화되고 헤더 타이틀이 동적 갱신됨 (예: "주변 소금빵 3곳").

| Sheet Mode | Height | 표시 |
|------------|--------|------|
| low | 96px | 핸들 + 필터 칩 |
| mid | 380px | + 추천 베이커리 리스트 |
| high | 640px | + 전체 베이커리 + 무드 그리드 |

### 화면 레이어
1. Map background (3 hint label: 성수동/한강/청담동/망원동/강남구청) - 다크모드 적용 시 검은 톤 아크릴 판 테마 지도로 실시간 전환
2. Star markers (mood color, hot 표시) - 카테고리 필터 결과에 따라 실시간 갱신 및 8개 슬롯 분산 배치로 핀 겹침 방지
3. Filter chips (날씨 / 카테고리 / 무드)
4. Marker 선택 시 mini-card
5. Bottom Sheet (3 mode drag)

### 권한
첫 진입 시 `ScreenLocationPermission` 오버레이.

### Action 진입점 (오버레이)
* **Notifications**: 매진 알림 및 소셜 알림 탐색 재진입점.
* **Settings**: 다크 모드 On/Off 스위치를 제공하며, 설정 시 HTML 문서 최상위 요소(`document.documentElement`)에 `data-theme="dark"` 속성을 실시간 동기화하여 CSS variables 기반 아크릴 판 다크 테마 적용. 로그아웃 기능 포함.
* **Saved Folders / Saved Bakeries**: 저장 아카이브 탐색.
* **Profile Edit / Taste Edit**: 개인 프로필 및 빵/분위기 취향 필터 재설정.
* **Taste Report**: 취향 분석 리포트 오버레이. 5차원 오각형 방사형 차트 꼭짓점 좌표에 따라 `textAnchor` 값을 동적으로 분기(`middle`, `start`, `end`)하고 X/Y 오프셋을 조절하여 텍스트 겹침 현상을 방지함.

## Overlay zIndex 및 Stack 렌더링 위계

Gluten은 단일 오버레이 관리에서 탈피하여 **배열 스택 구조 (`overlayStack = []`)**로 개편되었습니다.
* **스택 기반 탐색**: 새로운 상세 페이지나 프로필 등을 열 때 기존 오버레이 위에 쌓이며(Push), 뒤로 가기 시 스택에서 제거(Pop)되어 이전 오버레이의 스크롤 위치와 상태가 그대로 보존됩니다.
* **z-Index 위계**: overlayStack에 담긴 순서대로 상위에 렌더링되며, 최종 컴포넌트 레벨에서의 기본 z-index 가중치는 아래와 같습니다.

```text
30  Detail-derived overlays (Review Write, Post Detail 등)
40  Bakery Detail
50  Save Folder Sheet (폴더 지정 시트)
60  Location Permission / SaveToast (샌드박스 토스트 알림)
```

스택에 하나라도 오버레이가 존재하면 메인 탭들과 Bottom Nav는 숨김 처리되거나 비활성화됩니다.
