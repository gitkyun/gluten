# UserFlow.md

# Gluten User Flow System

## User Flow Goal

This document defines:
- core exploration loops
- emotional progression
- exploration expansion behavior
- save/review behavior
- re-exploration structure
- interaction continuity

The purpose is not task completion mapping.

The purpose is:
- exploration rhythm design
- emotional continuity
- taste accumulation flow
- discovery expansion logic

---

# Core User Philosophy

Traditional apps optimize:
- search completion
- utility efficiency
- task completion

Gluten optimizes:
- exploration continuity
- emotional curiosity
- taste accumulation
- archive behavior
- discovery expansion

---

# Core User Loop

```text
Explore
→ Detail
→ Save
→ Exploration Expansion
→ Visit
→ Review
→ Taste Accumulation
→ Re-exploration
```

This loop defines the entire product behavior.

---

# Emotional Flow

```text
Keep exploring
→ Want to visit
→ Want to save
→ Want to share
→ Feel taste accumulation
```

Gluten is designed around emotional continuity, not utility completion.

## 10.1 Onboarding Flow

### Goal
첫 진입에서 취향을 수집하고 일반/사업자 분기로 분배.

### Step

```text
Splash
  ├─ orbit mood dots 애니메이션
  └─ → Login

Login
  ├─ 이메일·비밀번호 입력
  ├─ → Reset 1 → Reset 2 (비번 재설정 분기)
  └─ → UserType

UserType
  ├─ 일반 유저 → Signup
  └─ 사업자    → BizSignup

Signup
  └─ → Taste 1 (빵 14종 선택)

Taste 1
  └─ → Taste 2 (분위기 12종 / 4 mood group)

Taste 2
  └─ → onComplete → Explore Tab
```

### Emotional State
```text
Splash       호기심
Login        신뢰
UserType     선택 자유
Taste 1·2    자기 탐색 + 게임감
```

### UX Principle
- 12 step 모두 fade 전환, 우상단 진행 없음 (단계 강조 안 함)
- 취향 선택은 Set 토글 — 다중 선택 가벼움
- 사업자 분기는 동일한 시각 언어, 다른 카피 톤

## 10.3 Save Flow (2단계 간편 저장 — Quick Save)

### Trigger
* 탐색 피드 카드(Explore Card, Near Sheet List, Social Feed Card 등) 또는 Detail 페이지의 별표(Star) 저장 아이콘 탭.

### Step
```text
저장 아이콘(Star) 탭
→ [Step 1] 기본 폴더('c1')로 즉시 북마크 처리 (저장 상태 활성화, icon filled)
→ [Step 2] 화면 하단에 샌드박스 토스트 알림 ("저장되었습니다 [폴더 변경]") 팝업 노출 (5초간 유지)
    ├─ [케이스 A] 토스트를 그대로 두거나 다른 영역 탐색 시: 5초 후 토스트 자동 소멸 (탐색 연속성 유지)
    └─ [케이스 B] 토스트 내 "[폴더 변경]" 텍스트 클릭 시:
         → Save Folder Sheet 슬라이드업 (z=50)
         → 폴더 선택 또는 새 폴더 생성
         → 저장 위치 변경 완료 (Sheet dismiss 및 상태 동기화)
```

### Auto-tagging
저장 시점에 다음을 자동 태깅:
- bakery.mood[] → taste profile
- bakery.region → local pattern
- 폴더 themes

### Emotional State
```text
소유감
취향 누적 실감
정리 만족
```

## 10.5 Settings / Logout & 테마 동기화 Flow

### Trigger
Profile 우상단 settings 아이콘 클릭.

### Step
```text
Profile
→ Settings 오버레이 진입 (overlayStack push)
   ├─ 다크 모드 토글 On/Off 변경 시:
   │    → document.documentElement에 'data-theme="dark"' 속성 실시간 동기화 탈부착
   │    → CSS 변수 var()에 바인딩된 배경, 폰트, 유리(Glass) 카드의 보더 및 그림자, 지도 미니맵이 다크 톤 아크릴 판 테마로 일괄 실시간 전환
   ├─ 기타 계정 설정 / 알림 설정
   └─ 로그아웃 → onboarded=false 설정 → Splash 화면으로 초기화 이동
```

### Principle
Profile은 archive 정체성을 유지하고 Settings는 별도 오버레이로 분리.

## 10.14 Search Flow (3 컨텍스트)

### Global Search
Bottom Nav floating search FAB → `ScreenSearch` → 베이커리·메뉴·지역·태그 통합.

### Near Search
Near 탭 검색 버튼 → `ScreenNearSearch` → 지도 컨텍스트 유지하며 검색.

### Social Search
Social 탭 검색 버튼 → `ScreenSocialSearch` → 게시물·유저·커뮤니티.

### Principle
검색은 컨텍스트별 분리 — 탭마다 의미가 다르므로 통합하지 않음.

## 10.17 Navigation State & Overlay Stack Flow

### 탭 화면 상태 보존 흐름
```text
탭 메뉴(Explore / Near / Search / Social / Profile) 간 이동 시
→ 컴포넌트를 언마운트(destroy)하지 않고 DOM에 상시 마운트 유지
→ active가 아닌 탭은 'display: none'으로 제어
→ 탭 전환 후 재진입 시 스크롤 깊이(Scroll Depth) 및 UI 상태가 그대로 보존됨
```

### 오버레이 중첩 스택 흐름
```text
새로운 오버레이 화면(Detail, Profile Edit 등) 진입 시
→ overlayStack 배열에 화면 컴포넌트 객체를 push하여 위에 중첩 렌더링
→ 뒤로 가기(Back) 터치 시
    → overlayStack 배열에서 pop 수행
    → 하위 오버레이 또는 메인 탭 화면의 스크롤 위치와 기입 내용이 온전히 유지됨
```
